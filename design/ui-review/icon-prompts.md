使用用户指定的火山方舟 API 与 Seedream 5.5，参考项目原创粉色图标的二维手绘形式。蓝色采用侧身迈步，黄色采用用户选定的坐姿，双前蹄直接与 D 字母相接，D 旁有圆点点缀。

## 蓝色动作与角度

以参考图中的原创浅蓝色小羊为角色和二维手绘画风参考，重新设计同款图标的动作与视角。角色身体向画面右侧转成三分之四侧面，正在轻快向右迈出一步，一只后蹄抬起，短尾巴从左后方露出；头稍微回过来看向观者，自信又可爱地微笑，双眼明亮，耳朵随动作自然展开。整体是斜侧面的动态姿势，和参考图的正面坐姿有清楚区别。小羊前方两只前蹄直接从两侧抱住一个完整的大写D，D稍微向右倾斜，前蹄直接压在D的字母轮廓上，D与手有自然遮挡。D本身是蓝色字母，孔洞可透出背景，绝对没有椭圆形底牌、圆牌、徽章、标牌、底板或圆环。头顶浅雾蓝色羊毛，奶白高光与淡蓝晕染，深蓝灰圆润手绘描边，柔和色块、少量水彩晕染。主体保持完整，不裁掉脚或头，主体占画布约80%，适合48像素桌面图标。极浅蓝白圆角方形背景，1024×1024。保持2D卡通插画，不画3D、真实材质或毛发。角色脸型、羊角、发型、身体比例独立原创，无现有动画角色服饰或标志，无其他文字水印，只有一个清晰的D。

精修参考图，保持二维手绘画风、浅蓝羊毛、侧身迈步动作和D构图。修正肢体：小羊严格只有两只前蹄与两只后蹄。保留左侧直接抓D竖笔的前蹄、从D孔洞侧边搭着字母的前蹄，以及画面下方两只后蹄；删除D左下边缘、身体右侧那只多余的小蹄，将该位置自然补成腹部浅蓝羊毛。并在D字母右上方的留白处增加三个小小的雾蓝色圆点装饰，大小稍有变化、疏密自然，和D有少许间距，只占极小面积。D本身完整清楚，依然与两只前蹄自然遮挡融合，无底牌、椭圆或徽章。其余角色脸型、发型、色彩、背景、角度、边框和画风保持原样。1024×1024。
