# 蓝色小羊头毛与羊角修订

使用用户指定的豆包 API，模型 `doubao-seedream-5-5-261028`。以项目当前原创蓝色小羊图标为编辑目标，先统一浅雾蓝头毛与两只暖米金短弯角，再用新图标和原动作图作为双参考编辑页面六种动作。图标继续导出 PNG、ICO、ICNS；页面动作保留透明背景与512像素、底部30像素的既有归一规则。

接口参考：[火山方舟图片生成教程](https://docs.volcengine.com/docs/ark/image-generation-tutorial?lang=zh)。

## blue-icon.prompt

对参考图做局部角色精修，保留当前2D手绘应用图标的画风、动作、视角、脸型、眼睛、耳朵、身体比例、抱住D的前蹄关系、蓝色D字形、D旁三个圆点、浅蓝圆角背景和整幅构图。只重点修改头顶羊毛与羊角：1）额头、刘海和头顶原来整片奶白色羊毛全部改成清爽的浅雾蓝色，主色约#A8CDE4、阴影约#8DB6D4。整片头毛都应明确看得出蓝色，绝对不能再有白色或奶白刘海、白色毛团、白色发卷或大片近白高光。用柔和的蓝色深浅层次表现毛团，不改成平涂一大块。2）新增且清晰画出两只完整的短小弯羊角，位于左右耳朵上方，分别从头毛外缘自然露出，不能被刘海或耳朵遮住。两角为柔和浅麦金色/浅暖棕色，与蓝毛有明显色差，深蓝灰细描边，每只角有两条简洁弧形纹路和圆润小弯尖，每只可见长度约为头宽的12%到15%，可爱克制，左右各一只，不能画成鹿角、头盔或巨大盘角，也不能把耳朵当成角。3）保留蓝灰轮廓线、柔和水彩色块和原创2D卡通形式，不要3D、写实毛发。主体完整不裁切，仍然只有两只前蹄、两只后蹄。不要改变D，不加椭圆牌、圆牌、徽章、衣物或其他字母，无文字水印。1024×1024。
