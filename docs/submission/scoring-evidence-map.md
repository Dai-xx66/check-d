## 2. 从分值反推的三条结论（这一节比表格重要）

**结论一：50 分不看你算法多聪明。**
需求价值 30 + 完成度 20 = 50 分，靠的是「真实痛点讲清楚 + 教学价值有依据 + 材料齐全 + 答辩答得上」。技术实现只有 25 分，且原文对它的定义是「平台功能应用是否合理」，**不是**「调度算法是否最优」。

→ 直接影响：M2 的算法不必卷到最优解，**"正确 + 稳定 + 能解释为什么这样排"就够拿分**。多出来的时间应该挪去做需求依据和答辩准备。

**结论二：完成度 20 分其实是"0 或 100"的开关。**
原文第五节：「材料不齐或不符合规范者，资格审查不予通过。」也就是说材料不全不是扣 20 分，是**直接出局**。同理匿名违规是「违者直接取消评奖资格」。

→ 直接影响：材料清单和隐私清单的优先级高于任何功能开发。

**结论三：初赛是资格赛，决赛才是 100 分战场。**
原文第七条：「初评（匿名网评）……**初评成绩仅用于确定入围资格，不计入最终成绩**。」

→ 直接影响：初赛阶段唯一目标 = **让评委相信这东西真能跑**（链接可访问 + 截图真实 + 大纲说清）。不要在初赛前把算法打磨到极致，那是决赛前该干的事。
