# 蓝色小羊身体配色修订

使用用户指定的豆包 API 和 `doubao-seedream-5-5-261028`，基于上一版蓝头毛、暖米金双角的七张现有图，只加强身体蓝毛与腹部的浅冰蓝。页面动作按既有规则归一到512像素，底部留30像素；图标同步导出PNG、ICO、ICNS。

## app_icon_mist_d.prompt

对参考图只做局部颜色精修，不重新设计、不改变姿势和构图。用户已经认可当前浅蓝头毛和两只暖米金色小角，必须完全保留头部、双角的大小形状与颜色、脸型、眼睛、表情、耳朵、轮廓线、动作、身体比例、四肢数量、小蹄和道具。此次只把身体部分的羊毛调得更蓝一些：躯干、胸前、手臂、腿部、后背和尾巴的蓝毛从现在接近白色的浅色改为清楚但柔和的浅雾蓝色，主色约#ABCFE6，阴影约#90B9D6，保留原来的水彩纹理和蓝色深浅层次；腹部原来明显奶白色的毛团改为稍浅的冰蓝色#C4DFF0，不能再是一大块奶白色。让身体与当前浅蓝头毛协调，但不是深蓝、藏蓝、宝蓝或高饱和色，不要把身体涂成没有层次的同一块颜色。脸与小蹄不需要变蓝，道具颜色不变。严格保持原来的二维卡通手绘风格，不要3D或写实，不改羊角、不增加物品或文字，不加椭圆形底板、徽章或白色贴纸边。图标的D字形、两只前蹄抱D的遮挡关系、D旁三个圆点、原有浅蓝圆角背景全部保持不变，完整保留原来的图标。1024×1024。
