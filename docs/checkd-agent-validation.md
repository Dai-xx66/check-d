## 交付与限制

模型密钥仅从仓库外配置由本机Node服务读取。实际密钥未写入Dart、assets、Git或响应。提交前检查暂存文件中没有该实际密钥。

档案/目标/聊天/操作历史目前按账号保存在本机，业务事项继续走现有同步；这不是智能体档案的多端云同步。生产JWT与额度RPC权限仍须队长在Supabase测试项目应用迁移后验证，本地内存测试不代替云端RLS验证。

原生Windows PDF/WebView、Android/iOS/macOS系统通知与打包没有在本机全部验证；Windows插件符号链接能力、Android SDK和iOS签名依赖各自开发环境。不得将Web构建或前台提醒时窗测试描述为所有平台后台通知已通过。没有新增无人值守的云端复盘调度服务。
