# 页面内小羊动作生成记录

使用用户指定的火山方舟 API 和 Seedream 5.5，以用户已选定的蓝、黄应用图标为角色参考，独立生成透明背景二维动作插画。应用图标资源保持已选定版本。

## slate / idle

从参考图中提取同一只原创浅雾蓝小羊角色，画它打招呼的独立透明背景插画。必须严格保持角色的脸型、深蓝灰圆润描边、浅蓝与奶白的羊毛分区、耳朵形状、深蓝卡通眼睛、头顶羊毛发簇与二维手绘画法，不重新设计角色。改变动作：正面略侧身站着，身体完整，一只前蹄自然抬起来向观者招手，另一只轻轻搭在肚子前，微笑、双眼明亮。严格两只前蹄与两只后蹄。移除参考图里的D字母和所有图标背景，只保留角色本身。输出真正透明Alpha背景的RGBA PNG，无圆角方框、无底色、无白边、无圆环、无椭圆牌、无地面或场景，脚下仅可有极淡很小的接触阴影。角色完整居中，主体占画面约85%，四周留少量均匀安全边距，轮廓在48到160像素展示时依然清楚。二维卡通平面柔和色块、轻微水彩晕染，不画3D或真实毛发，无其他文字水印。1024×1024。
